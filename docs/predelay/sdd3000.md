# Korg SDD-3000 — researched circuit/spec (for PreDelayBlock kSDD3000 voicing + controls)

Deep-research pass 2026-07-03 (method per `docs/predelay/NEXT_CHARACTER_HANDOFF.md`). Target = the
**original 1982 rackmount Korg SDD-3000** (The Edge/U2 preamp-delay), cross-checked against the
**UAD SDD-3000** plugin whose panel Robbie referenced. Unlike the BBD pedals this is an early
**DIGITAL** delay, so the "circuit" that matters is the converter (bit depth/bandwidth), the analog
**input preamp** (its signature), the regeneration filters, and the modulation. Strong sources here
(better than the BBD pedals): **Korg's own 2014 developer interview**, the **UAD manual** (UA
reverse-engineered a golden unit), the **original owner's manual** (Internet Archive OCR), the
**Korg SDD-3000 PEDAL spec** (reissue that reproduces the filter section), and the **Aion FX
"Eclipse"** preamp schematic.

Everything below is cited; (inference) = derived, (unverified) = not confirmed by a reachable source.

## Signal path (stage by stage)
mono guitar → **analog INPUT PREAMP** (attenuator −30/−10/+4 dB → LEVEL/gain → JRC4558D gain stage
+ TL072 buffer, ±15 V rails; drive it hard = saturation/"crunch") → **A/D (12-bit + 1 = ~13-bit
companded)** → **digital delay memory (0–1023 ms, 1 ms steps) + regeneration** (Feedback, INV,
HOLD, and the LOW/HIGH filters in the loop) with **delay-time modulation** (Tri/Square/Random/Env) →
**D/A** → **LEVEL BALANCE (dry/wet crossfade)** → analog OUTPUT stage (attenuator −20/−10/+4 dB, JRC
op-amps, active in bypass) → mono/stereo out. Fixed ~17 kHz bandwidth (NOT clock-swept).

## Facts that drive the DSP voicing (cited)
- **Converter = "12-bit + 1" ≈ 13-bit companded** → deliberately "gritty/organic," low-resolution,
  rougher. Korg degraded modern DSP to match it; the character is NOT only the preamp (also the
  AD/DA losses + the modulation structure). → Korg dev interview https://www.korg.com/us/news/2014/1101/
  ; UAD manual https://help.uaudio.com/hc/en-us/articles/33194525793684-Korg-SDD-3000-Digital-Delay-Manual
- **Bandwidth: delayed signal 10 Hz – 17 kHz (+0.5/−3 dB), FIXED** (dry path wider, ~20 kHz). THD
  0.03 %, 94 dB dynamic range, "no compander breathing." The delay runs at a **fixed sample rate
  with a variable memory read** (not a variable clock), so bandwidth is CONSTANT vs delay time —
  the opposite of a BBD. → https://www.vintagedigital.com.au/korg-sdd-3000-digital-delay/ ; UAD manual
- **Max delay 1023 ms** (= 2¹⁰−1; 10-bit ms counter), min 0, 1 ms steps, ONE continuous range (no
  sub-bands on the original). → vintagedigital; UAD manual
- **Input preamp = the signature.** JRC4558D gain stage + TL072 buffer, ±15 V. The **Attenuator is
  counter-intuitive: −30 dB = MOST gain (instrument/Hi-Z), +4 dB = LEAST**; at −30 dB an EXTRA gain
  stage (the buffer) is engaged. **Driving a hotter signal than the setting expects → saturation /
  "crunch" that aficionados love** (the mojo; The Edge/Lanois used it as a +10 dB boost even on
  bypass). Input Z is pickup-interactive (value unverified); no input transformer (op-amp front
  end). → Korg interview; UAD manual; Aion Eclipse doc https://aionfx.com/app/files/docs/eclipse_documentation.pdf
- **Output stage** = same JRC-op-amp analog design, attenuator −20/−10/+4 dB, **active in bypass**
  (the boost trick). Mono in, stereo out. → Korg interview; UAD manual
- **REGENERATION.** FEEDBACK (self-oscillates high); **INV = inverts the feedback polarity**
  ("hollow" chorus/flange via phase cancellation); **HOLD = freeze the full 1023 ms buffer** (delay
  + feedback locked at max, filters/INV/mod still live). The **LOW/HIGH filters affect ONLY the
  delayed signal and recycle through the feedback** (so repeats are progressively filtered). →
  original owner's manual; UAD manual
- **FILTER values (from the Korg SDD-3000 PEDAL spec, which reproduces the original):**
  **LOW = low-cut/high-pass at Flat / 125 / 250 / 500 Hz, −3 dB/oct**; **HIGH = high-cut/low-pass at
  Flat / 8 k / 4 k / 2 k Hz, −6 dB/oct.** (Directions confirmed by the UAD manual; slopes are
  pedal-spec-sourced → (mostly-verified).) → https://www.korg.com/us/products/effects/sdd3000_pedal/specifications.php
- **MODULATION modulates the DELAY TIME.** Waveforms: **Triangle, Square, RND (random/S&H), ENV
  (envelope follower — louder input → SHORTER delay)**. **FREQUENCY 0.1–15 Hz** (in ENV mode it
  becomes the envelope release time). **INTENSITY = depth; at max the delay swings 2:1 (100 % → 50 %
  of the displayed time) and modulation is always SHORTER**, and its depth is COUPLED to the delay
  time (scales with it — a signature early-digital gotcha). → original owner's manual; UAD manual;
  Korg interview
- **LEVEL BALANCE = dry/wet CROSSFADE** ("at 0 only Direct, at 10 only Delayed"). Like the Memory
  Man, NOT the DD-7/Carbon Copy dry+wet law. → original owner's manual; UAD manual

## Could NOT verify (do NOT build hard numbers on these)

- Numeric **input/output impedance** (confirmed pickup-interactive, no ohm value published) → the

- **RND-mode FREQUENCY behavior** — the original manual says FREQUENCY sets the RND rate; the UAD

- The precise **preamp gain in dB** per attenuator position (anecdotal "~10 dB").

## → kSDD3000 voicing + controls decisions
- **bbd = false; maxTimeMs = 1023; antiAliasHz ≈ 16 kHz (FIXED ~17 kHz bandwidth); satDrive ~0.18
  (13-bit companded grit, in-loop); presHz 3400/+2.5 (early-digital presence sheen); fbCeiling 1.02;
  glide 30 (digital, quick time move, not a BBD swoop).** These stay from the prior voicing.
- **CROSSFADE Level Balance** (shared with the Memory Man): `(1−mix)·dry + mix·wet`.
- **NEW authentic controls (shown only for the SDD), matching the real front panel:**
  - **Input preamp drive** (`predelaySddInput`) + **Attenuator** (`predelaySddAtten` −30/−10/+4) —
    a front-end soft-clip whose drive rises as Input goes up and as the attenuator goes toward −30
    (the extra-gain-stage crunch). Colors dry + wet (the preamp is always in circuit).
  - **Feedback INV** (`predelaySddInvert`) — flips the feedback polarity in the loop.
  - **LOW filter** (`predelaySddLoCut` Flat/125/250/500) = in-loop high-pass; **HIGH filter**
    (`predelaySddHiCut` Flat/8k/4k/2k) = in-loop low-pass. Both recirculate (progressive on repeats).
  - **Waveform** (`predelaySddWave` Triangle/Square/Random/Env), **Frequency** (`predelaySddFreq`
    0.1–15 Hz), **Intensity** (the existing Mod knob) — SDD mod is UNIPOLAR/SHORTER and scales with
    the delay time (up to −50 % at full Intensity); ENV mode uses an input envelope follower.
- **Panel = the real control complement:** knobs Delay / Feedback / Balance / Intensity / Frequency
  / Input, and switches Waveform / LOW / HIGH / Attenuator / Invert. (Pan/Position and the pure
  output-level trims are stereo/utility and omitted for this mono block; HOLD/Wet-Solo deferred.)
